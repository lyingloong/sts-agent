# StS1 Static Knowledge Snapshot

This directory is a Git-tracked snapshot of public Slay the Spire 1 data used
only as fallback knowledge. It is generated by `tools/fetch_card_knowledge.py`
from `nkhoit/spire-archive` and is never fetched at controller runtime.

## Source And Scope

- Source repository: `https://github.com/nkhoit/spire-archive`
- Source path: `data/sts1/` on the repository's `main` ref
- Contents: every top-level StS1 JSON resource plus its 13 localization files.
- Output naming: `sts1_<source path>`; for example `sts1_cards.json` and
  `sts1_localization/zh.json`.

The snapshot is intentionally tracked so data changes are code-reviewed with
the controller changes that consume them. Refresh it with:

```powershell
python tools\fetch_card_knowledge.py
git diff -- data/knowledge
```

## Local Corrections

The source parser has a small set of known text defects. They are applied by
the explicit `ENTITY_OVERRIDES` table in `tools/fetch_card_knowledge.py`,
recorded again in `manifest.json`, and covered by unit tests:

- `DUPLICATIONPOTION`: remove concatenated upgraded text.
- `LIQUIDMEMORIES`: remove concatenated upgraded text.
- `ATTACKPOTION`, `COLORLESSPOTION`, `POWERPOTION`, `SKILLPOTION`: remove
  concatenated upgraded text.
- `SMOKEBOMB`: remove unrelated event text.
- `SWIFT_POTION`: restore `Draw 3 cards.` word order.
- `IMPULSE`: restore the missing historical beta-card base and upgraded text.
- 21 `powers` entries: remove concatenated base/upgraded descriptions. The
  affected Power IDs are fully enumerated in `manifest.json`.

These corrections are deliberately per-ID rather than heuristic text cleanup.
Static data never overrides concrete state received from CommunicationMod.
