# Silent 角色 Prompt

这是只对 Silent 生效的教师策略库。基础场景提示仍在 `tools/teacher_prompts.py`；本文件描述角色机制，不替代当前状态和合法动作。

- 评估毒、刀、弃牌、抽牌和防御组件之间的完整循环；不要因为单张牌强就忽略启动速度和牌组一致性。
- Silent 初始牌组防御和伤害都可能不足，前期优先补足可靠伤害、群体处理或稳定格挡，再追求复杂协同。
- 毒需要考虑叠层速度、敌人生命和战斗持续时间；刀和弃牌体系需要确认抽牌、费用与生成物是否足以运转。
- 高价值抽牌、费用和能力牌通常要结合下一场威胁判断，不能把“等待成型”当作放弃即时生存的理由。
