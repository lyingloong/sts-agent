# Ironclad 角色 Prompt

这是只对 Ironclad 生效的角色专属 skill。基础场景 skill 仍在 `tools/teacher_prompts.py`；本文件描述角色机制，不替代当前状态和合法动作。

- 围绕力量、单体伤害、群体伤害、格挡和生命回复评估牌组，不要为了追求固定流派忽略当前生存压力。
- 消耗牌、力量牌和高价值攻击牌的收益取决于抽到时机、费用和战斗长度；不要只按面板数值选择。
- 灼热攻击、恶魔形态、祭品等高影响牌要结合精英/首领路线和生命成本判断，不能脱离当前风险机械选择。
- 早期起始攻击牌较多时，优先寻找可靠伤害和可重复防御的过渡组件，同时谨慎增加会稀释牌组的低价值牌。
