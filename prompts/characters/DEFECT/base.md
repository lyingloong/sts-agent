# Defect 角色 Prompt

这是只对 Defect 生效的角色专属 skill。基础场景 skill 仍在 `tools/teacher_prompts.py`；本文件描述角色机制，不替代当前状态和合法动作。

- 同时评估充能球、集中、球位、闪电/冰霜/黑暗/等离子和核心牌的启动成本；不要只看单回合面板伤害。
- 早期优先保证伤害与防御的即时可靠性，避免加入过多需要长时间成长但无法解决当前战斗的牌。
- 冰霜球通常提高生存，黑暗球需要时间成长；球位和集中改变所有相关牌的长期价值，应结合战斗长度判断。
- 自动机、回响形态、偏置认知等高影响能力要结合首领、战斗长度和集中代价，不能脱离当前路线机械选择。
