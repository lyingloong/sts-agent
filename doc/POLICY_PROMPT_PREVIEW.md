# 本地策略 Prompt Preview

本文件是给开发者阅读的完整 Prompt 示例。它按照 `sts_agent.policy.local_qwen` 当前的实际拼接顺序整理，便于检查中文表达、字段组织和输出协议。

实时运行时，`当前场景提示`、`可见游戏状态` 和 `合法动作` 会根据游戏状态变化；其他内容基本固定。真正的训练和推理 Prompt 始终由代码生成，本文件不是运行时读取的配置。

## 战斗场景示例

下面是一份带有示例状态和合法动作的完整概率评分 Prompt。实际运行时，最后的模型续写只能是一个动作 ID。

## 代码对应关系

- 固定规则和场景提示：`build_prompt`、`build_scoring_prompt`
- 状态自然语言渲染：`render_observation`
- 合法动作渲染：`action_prompt_lines`
- SFT 目标：在最后的 `请输出唯一的动作 ID：` 后拼接正确动作 ID 和换行
- 地图可见性：由 `communication_controller.route_policy_observation` 先完成路由，渲染器再次确保非地图场景不输出 `地图全貌`
