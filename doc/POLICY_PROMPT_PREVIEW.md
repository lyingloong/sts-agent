# 本地策略 Prompt Preview

本文件对应 `sts_agent.policy.local_qwen.build_scoring_prompt` 的拼接结果。实时状态由
`render_observation` 和 `action_prompt_lines` 生成；下面用一个战斗 observation 展示完整
`canonical` 版式。值是示意数据，实际实体描述、合法动作和历史均以游戏状态为准。

训练/评分可选三个等价布局：

- `canonical`：通用指令 → 场景提示 → 状态与合法动作 → 单动作答案提示。
- `state_first`：状态与合法动作 → 场景提示 → 通用指令 → 单动作答案提示。
- `decision_first`：通用指令 → 状态与合法动作 → 场景提示 → 单动作答案提示。

三种布局内容相同，只调换区块位置；不是三条不同标签或三倍数据。MAP 与 COMBAT 使用不同场景
提示文字；完整地图只会在 MAP 的状态正文中出现。战斗内选牌仍带当前战斗状态。
提示词不含静态实体数据库、实体经验或 Boss 攻略。

## 代码对应关系

- 通用规则：`_policy_prompt_prefix`
- 统一场景分类：`sts_agent.policy.scenes.scene_key`（SFT/本地/远程共用）
- 本地场景提示：`_SCENE_GUIDANCE`
- 状态自然语言：`render_observation`
- 合法动作及标签：`action_prompt_lines`
- 最终拼接和三个布局：`build_scoring_prompt`
- MAP/非 MAP 地图隔离：`controller.route_policy_observation` 与 `render_observation`
- SFT 训练布局轮换：`sts_agent.learning.sft.EncodedDataset`

## 场景提示片段

下列片段拼接在通用指令和状态之间；完整状态仍来自上述渲染器。

```text
MAP：这是地图界面。根据完整公开地图、当前可达节点、生命、牌组、金币、药水和本幕首领比较后续路线；兼顾补强、营火恢复或升级、商店和精英风险，只选择当前合法的可达节点，不臆测问号房内容。
SHOP_ROOM：这是商店房间，还未打开商品界面。区分进入商店房间、打开商人和离开房间；按合法动作查看商人，不猜测未展示商品。若本局记忆表明已经访问并离开该商人，不要重复进入。
SHOP_SCREEN：这是商人界面。比较全部可见商品的效果、价格、当前金币和牌组缺口，以及移除牌的价值；考虑后续资源需求，不按名称或稀有度盲目购买。离开商人界面和离开商店房间是不同动作。
COMBAT_CARD_SELECTION：这是战斗内生成选牌，不是普通战后永久卡牌奖励。读取触发来源、描述和最近动作，确认卡牌进入手牌或其他位置、临时费用和持续时间；结合当前能量、敌人意图和手牌比较即时收益，不要因担心永久牌组变大而跳过。不知道的来源效果保持未知。
GRID_CONFIRM：这是选牌后的确认界面。查看待确认卡牌、已选项目和本次升级、移除或变化目的，决定确认或按合法动作返回重选；不是重新选择另一张牌的阶段。
```

GRID 还分别提供移除、升级、变化和一般选择提示；HAND_SELECT、翻牌事件、遗物触发选牌、
宝箱、过渡、终局和未知界面均有对应提示。全部提示原文以 `_SCENE_GUIDANCE` 为准。
