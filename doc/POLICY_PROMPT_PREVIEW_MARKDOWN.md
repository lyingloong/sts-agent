# 模型 Prompt Preview：Markdown 格式（待开发）

本文件展示与原 `plain_text` 格式并列的可选 Markdown 格式方案：固定章节、自然语言实体说明、精简的房间历史、单动作输出。它不作为原格式的升级或替代版本；默认继续使用原格式。每个代码块都是一次独立决策的完整输入，可以直接审阅拼接后的效果。

**当前状态：Markdown 格式待开发，尚未实现 renderer。** 基线单动作 API 的 `policy.api.prompt_format` 默认值为 `plain_text`；`markdown` 仅登记为待开发选项，显式选择时配置校验会报错。原格式及其生成示例见 [POLICY_PROMPT_PREVIEW.md](POLICY_PROMPT_PREVIEW.md)。本文是手工编写的格式方案，不由现有预览脚本生成。战斗示例改写自真实请求；其他示例是独立的构造数据，不组成一条连续轨迹。

## 展示约定

- 保留影响决策的信息：角色、进阶、幕和楼层、生命、金币、Boss、钥匙、完整牌组、遗物、药水，以及当前场景的公开状态。
- 卡牌种类 ID 保留；实例通过手牌位置或当前选牌列表位置区分。奖励使用 `R1` 等短编号，保留所属和互斥关系。UUID、事务编号、状态哈希不进入模型正文。
- 卡牌的名称、类型、费用、升级状态、效果各有明确位置。`+` 表示升级一次；若升级次数大于一次，另写次数。手牌使用本回合费用；与基础费用不同时，两者都写。X 费用写成“X费”。
- 战斗中写“当前牌面单段伤害”和“当前牌面格挡”。这些是游戏的当前缓存值，不再叠加我方力量、虚弱等修正，也不代表对每个敌人的最终扣血。敌人的格挡和状态效果独立保留。
- 效果说明保留完整语义。基础伤害等与当前值不同且有意义时保留；当前数值未知时，不能拿基础值冒充当前值。无关的 `-1` 哨兵值不直接作为伤害、格挡或费用展示。
- 完整说明已经包含的信息不再重复打印 `raw_description`、来源标记和相同的 tooltip。消耗、虚无、保留等真实属性继续显示。说明缺失、数值未解析或状态未知时，明确显示“未知”或“说明不完整”，不能默认成零、否或没有。
- 词条取游戏提供的实际解释并去重。空药水槽合并为容量/空槽数；非空药水仍保留栏位、效果、目标要求和当前可使用性。
- 完整地图仅在地图界面出现。战斗保留抽牌、弃牌、消耗堆的数量；当前模型投影尚不提供这些牌堆的逐张明细。
- 当前房间最多展示最近 30 步，注明总数、显示数和省略数。历史保留动作对象、目标、触发来源、选牌目的、确认/取消语义；不重复实体属性、执行来源或动作后的状态变化。
- 原先笼统的“当前界面内容”改为“商品”“选牌”“奖励”等具体章节；不生成空章节。流程事实只在相关场景展示，例如“本次为再次打开商人”，不打印全局的商店访问坐标列表。
- 合法动作仍由 controller 提供和编号。本文只提出展示方式，不增加自动动作或改变动作粒度。

每个输入开头保留一份简短任务与输出规则。场景提示只有一到两句；具体的遗物限制、选牌要求和营火规则随当前状态出现。相同 HP、相同基础/本回合费用、相同伤害字段不重复展开。
